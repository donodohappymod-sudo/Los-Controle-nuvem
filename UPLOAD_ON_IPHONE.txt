LOS COLLECTOR — UPLOAD SEM PASTAS

Esta versão foi achatada para facilitar o envio pelo GitHub no iPhone.
NÃO renomeie os arquivos que contêm "__". Eles representam pastas.

Exemplo:
app__page.tsx -> app/page.tsx
app__(dashboard)__dashboard__page.tsx -> app/(dashboard)/dashboard/page.tsx

O Dockerfile reconstrói automaticamente as pastas durante o build no Render.
Você não precisa criar essas pastas manualmente.

Importante: envie TODOS os arquivos desta pasta para a raiz do repositório GitHub.

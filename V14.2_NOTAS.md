# Controle Nuvem V14.2 ULTRA

Atualizações desta revisão:
- Motor visual procedural de fundo com cenas de galáxia, combate, corrida neon, arcade e cockpit.
- 10 estilos de controle com geometrias e materiais diferentes, não apenas troca de cores.
- Feedback de toque/pressão com escala, brilho e estado visual.
- WebSocket corrigido: controller agora entra na sessão pela URL correta (`role=controller&code=...`).
- Inputs corrigidos: botões e joystick são enviados como `control` + `payload` e aparecem corretamente no receiver.
- Ping/pong de latência adicionado.
- Social Gate conectado ao Instagram configurado no servidor, com fallback para @losmiguel_rs.
- Link do Instagram presente no rodapé.
- Endpoint público `/api/public-config` para o frontend ler configurações públicas sem expor segredos.
- Login administrativo mantém credenciais apenas no servidor.
- A senha administrativa não é armazenada no HTML.
- Não há credenciais de pagamento ou segredos embutidos no frontend.
- O Social Gate não finge verificar o follow: o Instagram não fornece essa confirmação de forma simples para este fluxo; o botão registra a ação localmente.

Para publicar:
1. Substitua os arquivos pelo conteúdo deste ZIP.
2. No provedor, configure `ADMIN_EMAIL` e `ADMIN_PASSWORD` nas variáveis de ambiente.
3. Rode `npm install` e `npm start`.
4. Painel: `/admin`.
5. Receptor: `/receiver?code=SEU_CODIGO`.
6. Controle: `/` e informe o mesmo código.
